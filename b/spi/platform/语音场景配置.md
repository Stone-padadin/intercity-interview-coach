# PID 11919 · SPI检测的原生语音控制场景

这是待账号配置的场景规范，不是已发布工作流，也不是官方可直接导入的工作流格式。使用官方“设备IoT控制”插件，通过当前产品物模型下发属性；不能用网页ASR关键词转串口替代平台实际调用。

## 物模型

保留11919已有音量等服务，新增独立“SPI姿态检测”服务。下面的编号为固件枚举值，**不是siid/piid**；实际服务与属性ID由平台生成，写入本机映射JSON再构建。

| 字段/建议名称 | 类型与访问 | 枚举/范围 |
|---|---|---|
| command / 检测控制 | 整数，可写 | 1开始、2标定、3暂停、4恢复、5停止、6查询 |
| state / 检测状态 | 整数，只读上报 | 0关闭、1等待基准或新帧、2标定中、3检测中、4暂停、5不可用 |
| pose / 有效姿态 | 整数，只读上报 | 0未知、1相对基准正坐、2持续肩线侧倾 |
| calibration / 标定状态 | 整数，只读上报 | 0未标定、1采集中、2READY、3拒绝 |
| samples / 标定有效样本 | 整数，只读上报 | 0..10，连续质量不足会归零 |
| result / 最近控制结果 | 整数，只读上报 | 0接受、1视觉不可用、2离线、3需先开始、4非法命令、5标定请求失败 |

设备上报是影子更新提交，不能仅凭SDK返回成功便认定平台已收到。需在平台实际查看上报变化。state=3只表示已有READY基准，仍须同时检查pose；pose=0可以是遮挡、未采到新帧或结果过期，不能称为正常姿态或危险。

## 六个语音场景

每个场景都使用当前11919产品及当前设备上下文，只写入上表command属性。保留现有设备插件与普通对话分支，不通过重新保存整个Agent草稿覆盖已有工作流。

| 场景名 | 示例说法 | 下发值 | 允许的即时答复 |
|---|---|---|---|
| 开始SPI检测 | 开始坐姿检测；打开姿态检测 | 1 | 已发送开始请求。首次使用或移动机位后，请先正坐并要求标定。 |
| 标定正坐基准 | 我已坐好，开始标定；重新标定坐姿 | 2 | 已发送标定请求，请保持机位固定，鼻子和双肩完整入镜，等待十个连续有效样本。 |
| 暂停SPI检测 | 暂停坐姿检测；先别检测 | 3 | 已发送暂停请求。 |
| 恢复SPI检测 | 继续坐姿检测；恢复检测 | 4 | 已发送恢复请求；需要设备返回新帧，才能判断当前姿态。 |
| 停止SPI检测 | 关闭坐姿检测；结束检测 | 5 | 已发送停止请求；再次使用需要明确开始。 |
| 查询SPI状态 | 检测开着吗；标定完成了吗 | 6 | 查询设备state、pose、calibration及samples；没有最新回执时说明暂时无法确认。 |

“开始”不自动标定，避免用户未就位时建立错误基准。只有用户明确表示已坐好且要求标定，才触发标定场景。重复的标定命令在采集中不会重新清零，但标定完成后再次要求标定会重建基准。

开始/暂停/恢复的成功执行须以实际设备上报为准。平台插件若只返回“已下发”，回答就保持“已发送请求”；不能说“已完成标定”或“检测正常”。若插件不能读取最新属性，查询场景明确告知尚无设备回执，不用LLM猜测。

## 组合流程

1. 用户“开始坐姿检测”→设备进入等待基准/新帧，推理提交启用。
2. Agent提示用户固定机位、鼻与双肩入镜。用户明确就位并要求标定→下发2。
3. 设备calibration=1并上报样本进度；calibration=2后仍须有有效新结果，才能报告pose=1/2。
4. 持续侧倾经过现有C去抖→pose=2；已核对接线且另行启用LED时才有橙灯。遮挡/过期→pose=0，不能沿用旧侧倾提醒。
5. 暂停→停止接收新的推理任务并清空可用结果；相机流和供电不等于关闭，不能把暂停当隐私物理遮挡。
6. 恢复→保留RAM里的基准，等待恢复后的新帧并重建去抖；机位变化必须重新标定。
7. 断线→关闭检测授权；重连后“恢复”被拒绝，须用户明确“开始”。重启后标定基准丢失。

本次没有添加主动打断当前对话的TTS侧倾播报。语音反馈指用户控制请求的原生Agent答复；姿态主动播报和自动触发云工作流要另验平台事件入口与音频仲裁。

## 实机验收

记录至少两轮真实语音、平台场景执行记录、实际siid/piid命令到达、设备状态上报四类证据。按开始→标定→独立正坐→左倾/回正→右倾/回正→遮挡恢复→暂停→恢复→停止执行。每个动作记录时间；推理历史约2秒一次，不能用相机帧率宣称提醒延迟。

同时说话时检查CPOSE、音频回复、内部RAM/PSRAM、panic与取流错误。物理LED默认关闭；没有接线验收不得为了演示开启。只看模拟测试、构建成功或平台文本回复均不能勾选实机通过。
