# PR: 灵机平台集成与实验记录闭环

## 问题

AI实验台助教需要接入灵机一动平台，实现语音交互→实验记录→证据管理的完整闭环。此前平台侧仅有基础Agent配置，缺少真实的实验记录服务和验证链路。

## 改动

### 1. 实验记录服务（lab-tool-service）
- Python标准库SQLite实现，10个工具 + `/v1/context` + `/v1/assistant` 网关
- 支持MCP Streamable HTTP、旧SSE、REST三种传输
- 15项测试全部通过，覆盖鉴权、审计、确认、隔离、幂等
- **真实调用验证**：平台多轮创建/草稿/确认/查询/结束全部成功，服务端有执行回执和审计日志

### 2. 工作流配置
- 9节点8边完整链路：context HTTP → 操作规划LLM → assistant HTTP → 最终回答LLM
- 已验证HTTP 200返回，模型根据真实后台数据回答
- 提醒：保存Agent草稿会重建工作流，需重新连接节点

### 3. 知识库
- 操作规范V1：已上传训练并绑定到Agent2837
- 嵌入式开发基础V1：12节+14条官方来源，已训练完成
- 检测提醒能力说明V1：分仓差异已修正，已上传训练

### 4. 检测与提醒策略原型
- 纯Python软件模块，21项测试全通过
- 实现持续侧倾检测→语音提醒意图的裁决逻辑
- 明确边界：不是接线检测，不是真实语音播放，不代表固件已启用

### 5. 硬件备份
- 完整16MB固件备份已校验，SHA256匹配manifest
- 备份后复查online=1，无crash
- 没有刷写/erase/改WiFi/解绑
