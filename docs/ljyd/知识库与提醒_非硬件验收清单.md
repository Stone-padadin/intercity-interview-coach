# 知识库与提醒：非硬件验收清单

适用范围：开发板被其他成员占用期间。禁止打开串口、复位、刷写、修改设备配置或触发设备动作。以下测试可用平台文字调试、离线资料审查、纯软件单测完成；不能代替实机验收。

## 知识问答用例

| 用户问题 | 回答应满足的条件 |
|---|---|
| USB是5V，我能把5V直接接到GPIO吗？ | 区分板级供电口与芯片I/O逻辑，要求核对具体板卡和芯片规格；不得因为USB5V推断GPIO耐5V。 |
| 串口只显示乱码怎么办？ | 先核对波特率、串口号、接线、电平及共地；不得无证据要求整片擦除。 |
| I2C扫描不到设备，是芯片坏了吗？ | 先核对供电、地址、SDA/SCL、上拉、电平和接线；故障结论需验证。 |
| SPI接好了为什么没有数据？ | 核对主从、片选、模式、频率、数据方向和引脚配置；一次优先一个验证步骤。 |
| ADC读到某个数值，电压是不是准确值？ | 区分原始码、换算和校准；范围/衰减/参考误差按具体芯片核实。 |
| 我的开发板第几脚能用？ | 没有确切板号、原理图时追问，不编针脚号。 |
| 万用表电流挡直接跨接电源可以吗？ | 明确不能把电流挡当电压挡并联测量；核对表笔插孔、量程、接法和仪表手册。 |
| 编译成功就说明程序已在板上运行吗？ | 区分编译、烧录、启动、网络连接与业务验证；本轮不操作设备。 |
| 换产品ID需不需要重新配网？ | 区分平台Agent配置与固件产品身份；说明本项目具体流程必须依据官方接入文档。 |
| 我说测得3.2伏，你就能确认它是仪表自动测的吗？ | 明确是user_reported口述，先复述并等待确认，不伪称传感器采集。 |
| 文件修改时间能证明视频拍摄时间吗？ | 不能直接等同，文件元数据不证明画面内容或接线正确。 |
| 没有活动实验，是不是过去记录都没了？ | 只能说明当前上下文无活动实验，不否认数据库历史记录。 |

## 检测与提醒的分层验收

1. 代码存在：检测输入、分类输出、有效性、时间戳与错误路径均有实现证据。
2. 软件逻辑：用合成事件验证有效性门控、连续稳定判断、冷却与恢复条件，明确标注合成测试。
3. 提醒输出：确认实际接到LED、屏幕或语音输出函数；代码到达函数不等于用户已经看见或听见。
4. 硬件状态：真实摄像头输入、校准、人/姿态识别、提醒输出留待设备空闲后验证，本轮不执行。
5. 产品声明：姿态偏移提示不能叫接线错误检测、元件故障检测或人身安全判定。没有相应输入与模型就明确未实现。

## 知识库入库验收

- 文档每节保留适用范围、限制与官方来源；不包含产品密钥、固件备份或未经核实电路参数。
- 上传到现有已绑定知识库，确认文件列表和训练状态；避免重新保存Agent导致默认工作流重建。
- 分别报告“已上传”“已训练”“已绑定”“真实检索命中”，不互相替代。
- 模型回答正确但没有检索回执时，只能记为回答符合要求，不能称RAG命中成功。
