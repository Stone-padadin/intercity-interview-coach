# 当前分工与联调顺序

更新：2026-10-31。当前方向为 AI 实验台助教；旧面试实现保留为复用基线。以下待办不是已完成声明。

## 先跑通一条真实记录

| 顺序 | 负责人 | 交付与验收 |
|---|---|---|
| 1 | B＋D | 保留可用固件/平台版本，核实当前 `online=0`；不先清配网或刷旧版 |
| 2 | A＋D | 冻结一个实验与事件契约，实现一条测量的待确认、修改、保存、刷新回读 |
| 3 | B＋A | 最终转写进入同一实验；重复事件不重复存；串口仅一个读取者 |
| 4 | A＋C | 取得真实台面视角，录一段可回放操作，能看清演示所需变化 |
| 5 | D＋A | 真实模型引用片段和已确认测量，给一项可区分原因的验证建议 |
| 6 | 全员 | 用户复测更新原实验；分别展示网页证据、设备输出和平台调用 |

第一轮不过，先不做护目镜、手指跟踪或自动运动。平台接入设探索时间预算，无法接通时采用明示的混合原型，见 [平台手册](platform.md)。

## A：网页与实验服务

- [ ] 从面试页面改成实验模板、测量点与会话，保留旧实现供回归。
- [ ] 待确认→补充/修改→确认保存→刷新回读，支持撤销、去重与实验隔离。
- [ ] 单一 USB 采集源、真实录像状态、回放、时间线、圈选与导出。
- [ ] 600 秒滚动保留与分析锁片，跨过十分钟边界后检查轮转及独立解码。

## B：设备与总联调

- [ ] 固定可运行版本，查当前离线状态，保留已通过语音路径。
- [ ] 最终 ASR 异步导出，带序号与启动时间；回调内不执行长 HTTP。
- [ ] 单串口桥接；时间映射、重启边界、去重与重试。
- [ ] 电脑结果真实播报，原生与外部回答排队，取消后不播放过期结果。
- [ ] 准备、记录、分析/复盘、暂停/结束状态；按实物验收 RGB 与平台控制。

## C：视觉、机位与结构

- [x] 独立工作副本软件回归，新增不发送命令的数值诊断工具。
- [x] COM7 被动连接与 45 秒采集，如实记录无姿态、当前离线。
- [ ] 与 B 核实当前固件 profile 和视觉开关；本轮不擅自切换或烧录。
- [ ] 用户方便后做当前机位标定、独立正坐、左右持续侧倾、回正、遮挡与恢复。
- [ ] 确认可用台面 USB 相机，与 A 检查对焦、反光、遮挡和回放时间定位。
- [ ] 复用本地 V0.5 手动调角结构，先局部固定与试装，不重做整壳或新增舵机/IMU。

当前仅确认系统列出 ASUS IR camera / ASUS FHD webcam，未证明有独立台面相机，也未取景。详见 [本轮 C 验证](validation-c-20261031.md)。

## D：平台、Agent、分析与材料

- [ ] 基于已通 Agent 新建实验角色版本和单实验知识库，保留旧版恢复路径。
- [ ] 核实工作流/工具条件，分别测试随机事实输入、播报、下一轮引用。
- [ ] 替换固定响应 Mock，选定真实模型，实测图像/视频输入、延迟和失败。
- [ ] 回答区分观察、推断与未知，引用事件/片段；复测后更新结论。
- [ ] 根据实际完成情况编写海报、演示、平台证据、配置与恢复说明。

## 共同验收

- [ ] 同一实验中的口述、确认保存、历史片段、分析、复测闭环。
- [ ] 新角色原生两轮对话、实际平台调用、语音与 RGB 状态一致。
- [ ] 当前机位 SPI 姿态；语音/视觉/灯光/录像/分析并发。
- [ ] 十分钟轮转、锁片和回放；断相机、断网、模型失败明确报错。
- [ ] 不同实验不串数据，失败不沿用旧结果，重连后可恢复。
