## 事实与边界

- 用户已确认旧 Agent 真实两轮语音可用；2026-10-31 被动检查观察到 `online=0, visual=0` 且没有姿态。两者分属不同时间，须查当前状态，不先清配网或刷旧版。
- C 实现与历史记录已存在，真人本轮验收延后。不沿用最初交接 PR 未合并的旧快照。
- SPI 看人，USB 看台面；系统列出相机不等于取景通过。现有肩线模型不识别护目镜、焊点或手指。
- A 面试页面和 D 固定响应 Mock 不是实验闭环。新契约需 A/B/D 联调固定，不能悄悄改旧字段而保留旧版本号。
- 平台插件不证明能任意挂 HTTP 或读取本地录像。播报不证明注入记忆，先测下一轮引用电脑独有事实。
- 当前 SDK 的 Agora 通用文本入口可能不支持，须查实际版本。混合架构明确电脑分析与平台对话各自职责。
- 十分钟回溯需真实录像、轮转、锁片与回放；现有 preview 程序不录像。
- 本地 V0.5 手动调角结构已有设计产物，打印装配未验收；不新加舵机/IMU或重做整壳。

## 执行与交付

1. 基于最新 main 建自己的 feat/<用户名>-<任务> 或 fix/ 分支。保留队友修改，不 reset/clean、强推或直接推送/合并 main。
2. 检查接口、GPIO4/8 冲突、电源与固件；提案不能写成已批准，跨目录仅改本次必要内容。
3. 先做一条真实记录与短片段闭环，再扩展600秒；防护、手指与机构后置。
4. 一台电脑一个串口读取者、一个录像采集源，预览复用该源。
5. 用 experiment_id/event_id 关联事件，区分设备与接收时间；测量确认、重试去重、实验隔离。事实、推断、未知分开。
6. 不提交密钥、设备身份、个人图像/音视频、原始日志、备份、SDK或产物，配置留在忽略目录。
7. 运行相关检查；C 用 scripts\Test-C.cmd 或 python scripts/test_c.py。软件通过不等于实物通过；设备操作前查端口占用，不擅自切换现用固件。
8. 更新文档、运行 git diff --check，只提交本任务文件，推送任务分支并建 PR，不自动合并。
