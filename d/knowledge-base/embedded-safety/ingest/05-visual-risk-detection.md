# 视觉危险操作识别

## 基本原则

视觉系统只报告画面证据和候选风险，不直接宣布“安全”。以下关键信息通常无法仅凭普通视频可靠确定：导线内部电流、电压等级、GPIO 耐压、电池化学体系、器件温度、示波器地与保护地关系、固件输出状态、保险和隔离是否有效。

输出必须区分：

- `observation`：画面直接可见，例如“手正在移动已接线导线”。
- `risk_hypothesis`：基于观察的候选风险，例如“可能在带电改线”。
- `missing_evidence`：仍需电源状态、仪表档位或器件型号等信息。
- `recommended_action`：一个保守的下一步，例如“暂停操作并确认断电”。

## 视觉事件类别

### V01 带电改线或插拔

可见线索：电源指示灯亮、设备运行，同时手在插拔杜邦线、移动裸线、夹取探头或更换模块。

限制：指示灯熄灭不证明断电；画面外可能仍有电池、USB 或电容供电。

动作：提示暂停，确认所有电源和储能状态后再继续。

### V02 导电物造成短路风险

可见线索：裸露线头、螺丝、镊子、焊锡屑或表笔同时接近相邻电源端子；电池端子无绝缘；金属工具放在通电板上。

动作：要求断电并移除导电物，不建议通过制造火花验证。

### V03 万用表误用候选

可见线索：红表笔位于电流插孔却跨接电源；电阻/通断档测量疑似通电电路；表笔同时跨接电池两极；表笔接触相邻针脚。

限制：档位、插孔标识和测量点必须清晰可见；无法看清时标记 `unknown`，不猜测。

### V04 焊接与热风风险

可见线索：烙铁离开支架、热端朝向线缆或人体、热风对着电池/塑料/易燃物、工作区无明显抽排、剪脚方向朝向人、裸手触碰刚加热区域。

限制：普通画面不能准确判断温度和烟雾成分。

### V05 电池异常

可见线索：软包电池明显鼓包、外皮破损、漏液、变色、冒烟、火花；电池被挤压、穿刺、折叠或靠近热风/烙铁。

动作：高优先级停止；出现烟、火、漏液或快速形变时触发撤离和现场应急流程。

### V06 烟、火花、火焰和熔化

可见线索：持续烟雾、火焰、电弧、周期性火花、塑料软化、绝缘层变形或发光异常。

限制：蒸汽、助焊剂烟和环境反光可能误报，但仍应先停止并人工确认。

### V07 机械卷入、夹伤和飞出风险

可见线索：手、头发、衣物、线缆接近旋转轴/风扇/轮子；高速转子无防护；机构运动区域内有人；改线时动力未隔离。

动作：触发停止运动或硬件急停提示，等待机构完全停止后再接近。

### V08 防护用品或环境问题

可见线索：剪脚、打磨、飞轮、强光操作时未见眼部防护；焊接区有饮料/食物；可燃物靠近热源；工作台杂乱导致裸线相互接触。

限制：PPE 可能在画面外，系统应提示确认而非直接定罪。

### V09 高压/市电暴露候选

可见线索：拆开的市电设备、裸露插头端子、开关电源一次侧、无外壳高压模块、示波器地夹接入疑似一次侧。

动作：归类 L3，停止提供操作步骤并要求具备资质的人员现场处理。

### V10 无人值守运行

可见线索：加热器、电池充电、马达或高功率负载持续运行，但画面中长时间无人且没有可见监控/联锁证据。

限制：单帧无法判断“无人值守”，必须使用持续时间窗口和实验状态信息。

## 时序与置信度

- 单帧：适合识别工具、烟火、明显鼓包和人员接近区域。
- 2 至 10 秒片段：判断插拔、带电改线、触碰热端、运动区域侵入。
- 长时间窗口：判断无人值守、反复过流重启和异常逐渐加重。
- `low`：目标模糊、遮挡或关键字段不可见，只提示人工确认。
- `medium`：观察较清晰，但缺少电源/型号/状态证据。
- `high`：危险现象直接可见，例如火焰、明显电弧、手进入运行机构。

## 输出格式

```json
{
  "event_id": "vision-0001",
  "experiment_id": "exp-001",
  "time_range_ms": [12000, 14800],
  "category": "V01_LIVE_REWIRING",
  "risk_level": "L1",
  "confidence": "medium",
  "observations": ["设备指示灯亮", "手正在拔出一根跳线"],
  "missing_evidence": ["外部电源状态", "USB 是否仍连接"],
  "recommended_action": "暂停操作并确认所有电源已经断开",
  "requires_user_confirmation": true
}
```

## 禁止的视觉结论

- 未检测到烟雾，所以电路安全。
- 没看到人，所以用户已离开或设备无人值守。
- LED 亮了，所以接线、电流和极性全部正确。
- 戴了手套，所以可以接触带电或高温部件。
- 看起来像 5 V 模块，所以可接 5 V GPIO。
- 画面中没有火焰，所以电池没有热失控风险。
