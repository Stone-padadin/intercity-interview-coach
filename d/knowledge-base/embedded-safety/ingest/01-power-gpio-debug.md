# 电源、GPIO、总线、USB 与调试器

## 上电前

1. 记录所有电源的电压、电流限制、隔离方式和公共地。
2. 核对板卡、芯片和模块准确型号；标出 `VIN`、`5V`、`3V3`、GND 与 GPIO。
3. 断电检查极性、短路、焊桥、连接器方向和芯片方向。
4. 分析 USB、电池、实验电源、调试器之间的反灌路径。
5. 首次上电使用保守限流，先验证各电源轨和静态电流。

## 危险操作

- 极性未确认就上电，或在通电状态移动裸线。
- 在面包板、杜邦线和小连接器上通过大电流。
- 把 `VIN`、电源脚和 GPIO 当成可互换端子。
- 给未供电器件的信号脚加电，造成保护二极管反向供电。
- 让两个推挽输出直接对打，或用 GPIO 直接驱动马达、继电器、灯带、加热器和大功率 LED。
- 仅凭“Arduino/ESP32/STM32”系列名猜 GPIO 耐压和输出电流。

## 通信接口

- I2C：确认上拉电阻由谁提供以及上拉到哪个电压域。
- SPI：确认片选默认态，避免多个器件同时驱动 MISO。
- UART：TTL UART 与 RS-232 电平不同，不可直接互连。
- CAN/RS-485：核对终端、共模范围、隔离和地参考。
- 相同连接器外观不代表相同引脚定义。

## USB、示波器与调试器

- USB 地和普通台式示波器地通常与保护地有关，错误连接可能直接短路被测节点。
- 普通示波器地夹不得连接到非隔离高侧节点。
- 调试器的目标电压检测脚不一定用于供电，按具体探头手册连接。
- 板载与外部调试器可能同时驱动线路；按板卡跳线说明隔离。
- 刷写前确认目标芯片、接口电压、固件来源和恢复方法。
