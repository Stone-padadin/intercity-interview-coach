# 嵌入式爱好者实验台安全知识库

面向 Arduino、ESP32、STM32、Raspberry Pi、传感器、执行器、焊接、电池和常见调试工具。将 `ingest/` 中的文件上传到同一个知识库；`sources.md` 和 `qa-tests.md` 用于人工审查与验收。

## 边界

本库覆盖常见危险类别，但不宣称穷尽“所有危险操作”。任何新器件、新能源、新工具、未知模块和特殊场地都必须重新登记风险。器件额定值以当前准确型号的数据手册为准。

## 风险等级

- `L0`：低压、低能量、有限流保护，无明显热、机械或化学风险。
- `L1`：外接电源、焊接、马达、继电器、成品锂电池包、未知模块等，需要检查表。
- `L2`：自制电池包、大电流、大型运动机构、加热器、强光/射频、高能电容，需要有经验人员现场监督。
- `L3`：裸露市电、未知高压、损伤电池继续使用、绕过保护、人体通电实验等。本库不提供操作步骤。

## 视觉识别

`ingest/05-visual-risk-detection.md` 定义可见危险、时序判断、置信度和人工确认规则。视觉模型只提供风险线索，不能单独证明电路安全，也不能替代电气测量、型号核对和现场急停。

`IMAGE_INDEX.md` 收录 7 张许可明确的视觉示例及归属说明，图片文件位于 `images/`。

## 立即停止条件

冒烟、火花、焦味、异常噪声、快速升温；电池鼓包/漏液/发热；导线或连接器发热；电源无故限流；无法确认电压、极性、引脚或残余储能；运动机构松动或防护缺失。
