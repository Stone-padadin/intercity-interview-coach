# 嵌入式操作问答链接知识库

用于回答嵌入式开发者在安装、配置、编译、烧录、调试、外设使用和 API 查询方面的问题。

## 使用规则

- 优先依据用户给出的准确芯片、模组、开发板、SDK 和工具版本检索。
- 数据手册、参考手册和官方 SDK 文档优先于教程页。
- 不同系列或版本的参数不得互相套用。
- 链接页面没有覆盖的问题，应明确说明资料不足，不编造寄存器、引脚或命令。
- 涉及供电、电池、高压、运动机构或热源时，同时检索危险操作知识库。
- `urls.txt` 为每行一个链接的纯文本导入源。
