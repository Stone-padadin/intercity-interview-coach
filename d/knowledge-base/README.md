## 回答与证据边界

- 查询具体接线、量程或额定值前，核对完整型号和实际电路；官方文档也不能证明现场状态。
- 已确认口述仍是 `user_reported`，不改标为自动仪器采集。
- 模型结论分开写可见事实、候选解释、未知和一个优先验证步骤，并保留真实片段时间。
- 没有视觉证据或状态未知不能当作安全确认；软件测试不证明危险操作识别效果。
- 来源页不可访问、图片模糊、参数不足或模型失败时说明缺失，不用固定答案替代真实结果。
