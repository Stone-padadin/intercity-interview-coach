# D · 实验助教 Agent、证据分析与展示

本目录是 AI 实验台助教的 Agent 接入位置，尚未包含新角色运行实现。既有面试 Agent 仓库与固定响应不能作为实验排错闭环验收。

## 本轮交付顺序

1. 保留已通语音角色，准备实验助教新版本和一个真实实验的资料。
2. 与 B/A 分别验证最终转写、电脑结果播报、下一轮引用电脑独有事实；播报成功不等于共享记忆。
3. 接入真实模型与真实操作片段、已确认测量。回答分为观察、候选原因、未知和一项优先验证，并引用真实记录/时间。
4. 用户复测后对比前后测量，更新原实验。相机遮挡、缺片、模型失败时明确说证据不足。
5. 根据实际验收结果制作海报和演示，人工复盘不称 AI 分析，不把规划写成已完成。

当前网页支持人工记录和人工复盘；语音、视频和模型未接入。先读 [产品范围](../docs/project.md)、[团队分工](../docs/team-plan.md)、[平台边界](../docs/platform.md) 与 [共享规则](../AGENTS.md)。配置与原始媒体不得提交。
